# Release Notes (v2.5)

## 新特性

此版本以`MySQL`为例，实验性地支持了在相同类型数据库之间迁移视图、触发器、存储过程、函数、用户和权限等。

此特性对于新建/重建备库，或者进行整个数据库实例迁移非常有帮助，欢迎体验。

## 连接器

### 优化 MySQL 连接器

* 支持在`MySQL`之间迁移视图、触发器、存储过程、函数、用户和权限；

### 优化 Oracle 连接器

* `CDC` 支持 `PDB` 架构；

### 新增 SQL Server 连接器

* 支持通过批量方式读取数据；
* 暂未支持基于日志订阅的 CDC 能力；
* 暂未支持数据写入能力。
